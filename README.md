Python Expense Tracker

A command-line expense management application built using Python.

Features:

1.Add and view expenses

2.Calculate total expenses

3.Delete expenses

4.Search expenses by category

5.Calculate monthly expenses

6.Save and load expenses using JSON

7.Validate user inputs

8.Automatically save expenses when exiting

Technologies:

1.Python

2.JSON

3.File handling

4.Exception handling

How to Run:

1.Install Python.

2.Download expense_tracker.py.

3.Open a terminal in the project folder.

4.Run:

  python expense_tracker.py

Learning Outcomes:

*This project helped me practise Python functions, lists, dictionaries, loops, JSON, file handling, and input validation.
